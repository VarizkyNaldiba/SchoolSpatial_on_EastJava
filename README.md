# SchoolSpatial on East Java

## Overview
**SchoolSpatial on East Java** is a GIS‑based analysis platform that visualizes and evaluates the distribution of schools across the East Java region.  
The project aggregates public education datasets, geocodes each institution, and produces interactive maps that help policymakers assess accessibility, identify underserved areas, and plan resource allocation.

## Objectives
- **Map every K‑12 school** in East Java with precise geographic coordinates.  
- **Analyze spatial equity** (distance to nearest school, population coverage).  
- **Generate actionable insights** for government and NGOs to improve educational infrastructure.
